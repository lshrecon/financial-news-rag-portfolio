# 金融ニュース検索とETF価格比較

2026年10月9日版。個人制作の修正用コピーから整理した検討用ソースです。ニュース検索、ETF価格比較、図・文章・出典の報告をLangGraphでつなぐ試作です。因果効果や投資成果を示すシステムではありません。

## 実装と最近の改善

BM25とFAISSで候補を取得し、BGE-M3で再評価して、ETFごとの記事と価格期間を比較します。最近のAI支援による点検で、次の処理を修正しました。

- 記事の時刻と質問の基準時刻を分け、その時点で観測できる価格だけを使用。
- 別ETFの記事日が他ETFの比較期間に混入しないよう、ETFごとに日付・価格・マクロ指標を保持。
- 過去記事のURL・日時・識別子もレポートへ渡し、同じ価格期間を二重計上せず出典を併記。
- 欠損値を0や期間外の価格で置き換えず、比較できない状態を返す。
- BGEの辞書型・単一値の戻り値、検索スコアの向き、候補統合、グラフの合流・分岐を整理。

再現用の合成例では、別記事の日付による99→49.5（−50%）の比較を、対象ETFの記事日による90→99（＋10%）に修正しました。これは不具合を説明する数値で、投資実績ではありません。

## 確認結果

修正用コピーでは、合成資料と代替応答による38件のオフライン回帰検査が通過しています。実際のLangGraph・BM25・FAISSを使用しますが、記事・価格・埋め込みは合成値、LLM等は代替応答です。検索精度や実LLMの回答品質を検証したものではありません。

実BGEの戻り値2ケースと、事前に固定した実記事4件の出典・価格照合は別の確認です。実記事・モデル・対応するローカル検証資料はこのZIPには含めません。記事URLを保つことと、生成文の主張が記事に裏づけられることも別です。

## 読む順序

- `price_windows.py`：価格期間と観測可能時点。
- `macro_windows.py`：ETF別の期間・マクロ指標の単位。
- `retrieval_contracts.py`：日時条件・検索スコア・BGE戻り値。
- `source_evidence.py`：記事識別子・URL・出典保持。
- `LangGraph.ipynb`：処理全体をつなぐノートブック。
- `offline_runtime.py`：必要な関数とグラフを取り出すオフライン検証。
- `tests/fixtures/pre_graph_repair.ipynb`：修正前の失敗を比較する合成検査用の旧コード。現行実装ではありません。

## オフライン検査の入口

既存の確認環境はWindows、Python 3.12.11、LangGraph 1.0.0、FAISS 1.12.0、pandas 2.3.1です。NumPy、matplotlib、langchain-community、langchain-core、rank-bm25等の依存ライブラリも使います。新規環境へのインストールは未検証です。

```text
python -m unittest discover -s tests -v
python offline_runtime.py
```

APIキーやモデル重みを使わない検査です。一部の統合検査は依存関係がないとSkipTestになるため、単なる「OK」だけでなく、38件実行・スキップ0件まで確認してください。`offline_runtime.py` は必要なセルを選んで使い、データ読込・API・モデル初期化を含む全セルを順番に実行するものではありません。実行すると合成レポート等を保存します。

## 既知の不具合と残る限界

- ノートブック末尾の診断セルには未定義の `model` 参照が残っています。全セル一括実行は未完了です。実サービスとして完成した状態とは扱いません。
- 米国東部時間16:00の通常終値を仮定し、休日・短縮取引・欠損営業日の取引所カレンダー照合は未実施です。
- モデル学習時点、記事収集時点、過去データの改訂を完全に管理していません。
- 検索の正解データ評価、ETFとの対応精度、生成文の根拠・引用、API認証・費用・障害復旧・日次無人運用は未検証です。
- 外部データや認証を使う元の経路には追加準備が必要です。FAISS/pickleの読込とWindows固有フォントの前提も残ります。

## 配布範囲とAIの利用

今回のコード修正・再計算・検査にはAIの支援を用いており、元の個人制作時の成果とは分けて記載しています。ノートブックの保存出力・添付・実行番号・メタデータは除去しました。元ニュースCSV、実記事の選定記録、FAISSインデックス、重み、キャッシュ、認証情報は含みません。`MANIFEST.json` は配布物のファイル対応とハッシュです。
