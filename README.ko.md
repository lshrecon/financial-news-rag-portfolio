# 금융 뉴스 검색과 ETF 가격 비교

기존 검사 결과를 포함한 일본어 원본 ZIP의 README를 본인 열람용으로 옮긴 문서로, 아래 ‘ZIP’·‘배포 자료’는 일본어 원본 코드 묶음을 뜻합니다.

2026년 10월 9일판. 개인 작업의 수정용 사본에서 정리한 검토용 소스입니다. 뉴스 검색, ETF 가격 비교, 그림·문장·출처 보고를 LangGraph로 연결한 시제품입니다. 인과효과나 투자 성과를 보여주는 시스템은 아닙니다.

## 구현과 최근 개선

BM25와 FAISS로 후보를 가져오고 BGE-M3로 다시 평가해, ETF별 기사와 가격 기간을 비교합니다. 최근 AI의 도움을 받은 점검에서 다음 처리를 수정했습니다.

- 기사 시각과 질문의 기준 시각을 분리하고, 해당 시점에 관측할 수 있는 가격만 사용.
- 다른 ETF의 기사 날짜가 비교 기간에 섞이지 않도록 ETF별로 날짜·가격·거시경제 지표를 유지.
- 과거 기사의 URL·날짜와 시각·식별자도 보고서에 전달하고, 같은 가격 기간을 중복 집계하지 않으면서 출처를 함께 표시.
- 결측값을 0이나 기간 밖의 가격으로 대체하지 않고, 비교할 수 없는 상태를 반환.
- BGE의 사전형·단일값 반환, 검색 점수의 방향, 후보 통합, 그래프의 합류·분기를 정리.

재현용 합성 예제에서는 다른 기사 날짜에 따른 99→49.5(−50%) 비교를, 대상 ETF의 기사 날짜에 따른 90→99(＋10%)로 수정했습니다. 이는 문제를 설명하기 위한 수치이며, 투자 실적이 아닙니다.

## 확인 결과

수정용 사본에서 합성 자료와 대체 응답을 사용하는 오프라인 회귀검사 38개가 통과했습니다. 실제 LangGraph·BM25·FAISS를 사용하지만 기사·가격·임베딩은 합성값이고, LLM 등은 대체 응답입니다. 검색 정확도나 실제 LLM의 답변 품질을 검증한 것은 아닙니다.

실제 BGE의 반환값 2가지 사례와, 사전에 고정한 실제 기사 4건의 출처·가격 대조는 별도의 확인입니다. 실제 기사·모델·관련 로컬 검증 자료는 이 ZIP에 포함하지 않습니다. 기사 URL을 유지하는 것과 생성 문장의 주장이 기사로 뒷받침되는 것도 서로 다릅니다.

## 읽는 순서

- `price_windows.py`: 가격 기간과 관측 가능 시점.
- `macro_windows.py`: ETF별 기간·거시경제 지표의 단위.
- `retrieval_contracts.py`: 날짜·시각 조건, 검색 점수, BGE 반환값.
- `source_evidence.py`: 기사 식별자·URL·출처 유지.
- `LangGraph.ipynb`: 전체 처리를 연결하는 노트북.
- `offline_runtime.py`: 필요한 함수와 그래프를 추출하는 오프라인 검증.
- `tests/fixtures/pre_graph_repair.ipynb`: 수정 전 실패를 비교하기 위한 합성 검사용 이전 코드. 현재 구현이 아닙니다.

## 오프라인 검사 실행 방법

기존 확인 환경은 Windows, Python 3.12.11, LangGraph 1.0.0, FAISS 1.12.0, pandas 2.3.1입니다. NumPy, matplotlib, langchain-community, langchain-core, rank-bm25 등의 의존 라이브러리도 사용합니다. 새 환경에 설치하는 과정은 검증하지 않았습니다.

```text
python -m unittest discover -s tests -v
python offline_runtime.py
```

API 키나 모델 가중치를 사용하지 않는 검사입니다. 일부 통합검사는 의존 라이브러리가 없으면 SkipTest가 되므로, 단순히 ‘OK’인지만 보지 말고 38개 실행·건너뛴 검사 0개까지 확인해야 합니다. `offline_runtime.py`는 필요한 셀을 선택해 사용하며, 데이터 읽기·API·모델 초기화를 포함한 모든 셀을 순서대로 실행하는 것은 아닙니다. 실행하면 합성 보고서 등을 저장합니다.

## 알려진 오류와 남은 한계

- 노트북 마지막 진단 셀에 정의되지 않은 `model` 참조가 남아 있습니다. 모든 셀의 일괄 실행은 완료되지 않았습니다. 실제 서비스로 완성된 상태로 취급하지 않습니다.
- 미국 동부시간 16:00의 일반적인 종가를 가정하며, 휴일·단축 거래·결측 영업일에 대한 거래소 캘린더 대조는 수행하지 않았습니다.
- 모델 학습 시점, 기사 수집 시점, 과거 데이터의 개정을 완전히 관리하지 않습니다.
- 검색 정답 데이터로 하는 평가, ETF와의 대응 정확도, 생성 문장의 근거·인용, API 인증·비용·장애 복구·일일 무인 운영은 검증하지 않았습니다.
- 외부 데이터나 인증을 사용하는 원래 경로에는 추가 준비가 필요합니다. FAISS/pickle 읽기와 Windows 전용 글꼴을 전제로 하는 부분도 남아 있습니다.

## 배포 범위와 AI 사용

이번 코드 수정·재계산·검사에는 AI의 도움을 받았으며, 원래 개인 작업 당시의 성과와 구분해 기재했습니다. 노트북의 저장 출력·첨부·실행 번호·메타데이터는 제거했습니다. 원본 뉴스 CSV, 실제 기사 선정 기록, FAISS 인덱스, 가중치, 캐시, 인증정보는 포함하지 않습니다. `MANIFEST.json`은 배포 파일의 대응 관계와 해시를 기록한 파일입니다.
